# Alphabetical Tag Index – Overview

The Alphabetical Tag Index feature is part of the [Tag Groups](https://publishpress.com/links/tag-groups) plugin. This feature allows you to show terms in a layout where they are automatically organized by their first letter. You can use either shortcodes or Gutenberg blocks.

Here’s a screenshot of the Alphabetical Tag Index feature from [our demo site](https://demo.publishpress.com/alphabetical-index/). We’re using a custom Unicode icon and a three column layout.
