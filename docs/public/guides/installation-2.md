# How to Install Tag Groups Free

The installation of the free version of the [Tag Groups](https://publishpress.com/links/tag-groups) plugin is straightforward. It can be installed using the same process as for other plugins on WordPress.org. Please follow these steps:

- Go to “Plugins” then “Add New”.
- Search for “[Tag Groups](https://publishpress.com/links/tag-groups)” and click “Install Now”.

![](https://docs-media.publishpress.com/publishpress-tag-groups/tag-groups-install-bc6b7c421d.webp)

Alternatively, you can click on “Upload Plugin” and then upload the [ZIP file](https://wordpress.org/plugins/tag-groups/). Or you upload the unzipped `tag-groups` folder to the `/wp-content/plugins/` directory. If you upload the unzipped files directly to your server, you may have to fix the file permissions for css and js files.

- Click on “Activate”.

![](https://docs-media.publishpress.com/publishpress-tag-groups/tag-groups-activate-1e6481f3b6.webp)
