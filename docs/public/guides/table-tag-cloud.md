# Table Tag Cloud – Overview

The Table Tag Cloud feature is available in the [Tag Groups](https://publishpress.com/links/tag-groups) Pro plugin. This display organizes tags in a table, with groups as headers. You can use either shortcodes or Gutenberg blocks for this feature.

Here’s a screenshot of the Table Tag Cloud feature from [our demo site](https://demo.publishpress.com/table-tag-cloud/). This example has a color scheme and we’ve added the number of results after each term.
