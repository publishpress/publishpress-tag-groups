# Accordion Tag Cloud – Overview

The Accordion Tag Cloud feature in the [Tag Groups](https://publishpress.com/links/tag-groups) plugin allows you display a tag cloud with your groups as accordion panels. You can use either shortcodes or Gutenberg blocks for this feature.

Here’s a screenshot of the Accordion Tag Cloud feature from [our demo site](https://demo.publishpress.com/accordion-tab-cloud/). We’ve added the post count and a color format for each term.
