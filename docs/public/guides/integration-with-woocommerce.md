# Integration with WooCommerce Attributes

[Tag Groups](https://publishpress.com/links/tag-groups) Pro is able to show tags and groups among product attributes. This feature heavily depends on the template and was tested with the default and other themes. It therefore may not work with all themes.

![](https://docs-media.publishpress.com/publishpress-tag-groups/woocommerce-attributes-tag-groups-b516ffb95f.webp)

Follow these steps:

1. Go to the **Taxonomies** settings and enable “Product tags”.
2. Go to the **Back End** settings, **Meta Box** tab, and enable the Meta Box for “Product tags”.
3. Go to the **Front End** settings, **WooCommerce** tab and activate “Display [tag groups](https://publishpress.com/links/tag-groups) with WooCommerce attributes”.
4. Go to a product and use the Meta Box to add tags in groups.
