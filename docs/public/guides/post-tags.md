# How to Show Tag Groups on Posts

Table of Contents

- [How to customize the Post Tags feature](#0-toc-title)
- [How to Add Tag Groups Elsewhere in Your Posts](#1-toc-title)

By default, WordPress posts usually show all the tags that belong to that post.

This default setting does not connect to the [Tag Groups](https://publishpress.com/links/tag-groups) plugin. So if you want to show all the tags that belong to a post, and also show their groups, you will need to change the default display.

If you want to display your tags sorted into groups, you can use the “Post Tags” feature. When activated, we insert a table with groups and tags at the end of the post content. The image below shows an example of the “Post Tags” feature display at the bottom of a post.

![](https://docs-media.publishpress.com/publishpress-tag-groups/tag-groups-for-post-63d2ca0c61.webp)

Because themes are hard-coded, we cannot insert the tags at any position. It is only possible to add them after the post content.

## How to customize the Post Tags feature [#](#0-toc-title)

You can customize the display of the Post Tags by going to [Tag Groups](https://publishpress.com/links/tag-groups) > Frontend > Post Tags.

![](https://docs-media.publishpress.com/publishpress-tag-groups/post-tags-9160275737.webp)

## How to Add Tag Groups Elsewhere in Your Posts [#](#1-toc-title)

If you need to show the tags groups of a post in another position, you can try doing this:

- Use one of the Tag Groups shortcodes and add it the the required place in your post.
- Add the parameter `tags_post_id=0`.
