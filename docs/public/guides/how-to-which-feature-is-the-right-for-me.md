Below you find a list of common cases that users need to achieve. Some of these features are available only in the Pro version.

## Tag Clouds [#](#0-toc-title)

Tag clouds show tags of selected groups. When your visitors click on a tag, they will be taken to a new page where they see a list with matching posts.

### Displaying Tag Groups [#](#1-toc-title)

#### I need to display the tags under tabs (arranged horizontally). The tabs should represent tag groups. [#](#2-toc-title)

→ Use the Tabbed Tag Cloud.

#### I need to display the tags in an accordion (stacked vertically and sliding up and down). Each slider should represent a tag group. [#](#3-toc-title)

→ Use the Accordion Tag Cloud.

#### I need to display the tags in under tabs (arranged horizontally). The tags should be sorted alphabetically into groups by their first letters. [#](#4-toc-title)

→ Use the Alphabetical Tag Cloud.

#### I need to display the tags in a table: I the first row are the groups and below in each column the tags of a group. [#](#5-toc-title)

→ Use the Table Tag Cloud.

#### I need to display the tags in one tag cloud. It should be possible to filter the tags by group or by name. [#](#6-toc-title)

→ Use the Shuffle Box.

#### I need to display a tag cloud but only those tags that belong to a particular post. [#](#7-toc-title)

Use any of the tag clouds with the parameter tags_post_id. For the current post you use tags_post_id=0.

#### I need to display a tag cloud but only tags of those groups that belong to a particular post. [#](#8-toc-title)

Use any of the tag clouds with the parameter groups_post_id. For the current post you use groups_post_id=0.

### Not Displaying Tag Groups [#](#9-toc-title)

#### I need to display the tags in a simple tag cloud. The tags of different groups should be mixed together and no group names should be displayed. [#](#10-toc-title)

→ Use the Simple Tag Cloud.

#### I need to display only a subset of particular groups in a simple tag cloud. [#](#11-toc-title)

→ Create a tag group for the tags that you want to display and use the Simple Tag Cloud.

## Other Ways to Display Tags [#](#12-toc-title)

#### I need to automatically display under each post the tags that belong to this particular post. Tags should be sorted by groups. [#](#13-toc-title)

→ Activate the Post Tag feature in the [Tag Groups](https://publishpress.com/links/tag-groups) settings.

## Lists of Posts [#](#14-toc-title)

#### I need a filter on my page where visitors first select a group and then some of the tags of this group. Every time they add or remove a tag, they should see a list of posts that match these tags. [#](#15-toc-title)

→ Use the Dynamic Post Filter.

## Other Ways to use Groups [#](#16-toc-title)

#### I need to display on a page the name of one or more tag groups or the number of tags in them. [#](#17-toc-title)

→ Use the Group Info shortcode.

#### I need a menu where visitors can select a group. They will then be taken to a list of matching posts. [#](#18-toc-title)

→ Use the [Tag Groups](https://publishpress.com/links/tag-groups) Menu shortcode.
