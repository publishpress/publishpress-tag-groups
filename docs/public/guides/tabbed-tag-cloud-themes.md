# Tabbed Tag Cloud – Themes

The Tabbed Tag Cloud allows you to display a tag cloud with your groups organized into tabs. The Free version of the [Tag Groups](https://publishpress.com/links/tag-groups) plugin provides one theme called “Delta” for your tabbed layouts. You can see a preview of “Delta” in this screenshot below:

![](https://docs-media.publishpress.com/publishpress-tag-groups/tabs-delta-theme-48bcf6a498.webp)

The Pro version of the [Tag Groups](https://publishpress.com/links/tag-groups) plugin provides more themes, plus the ability to [create your own themes](https://taxopress.com/docs/creating-your-own-theme/). To choose a default theme, go to “Tag Groups” in your WordPress admin menu, then “Front End” and “Themes and Appearance”.

**Please note**: Your choice of theme will automatically apply to all the Tabbed Tag Cloud and Accordion Tag Cloud displays on your site. These themes can’t be applied to individual displays.
